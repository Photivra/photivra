## calculatePhotoelectrons

Converts mean incident photon count to mean photoelectron count.

This is an expectation value; the stochastic shot-noise realization is not
generated by this deterministic calculation.

```ts
export function calculatePhotoelectrons(
  input: CalculatePhotoelectronsInput
): CalculationResult<number>;
```

This call is synchronous; any supplied provider must follow its explicit synchronous contract.

## calculateSignalToNoise

Calculates expected SNR from Poisson shot noise and independent RMS read
noise.

Variances are combined as signalElectrons + readNoiseElectrons^2.
Dark current, fixed-pattern noise, quantization, clipping, and downstream
processing are intentionally outside this primitive.

```ts
export function calculateSignalToNoise(
  input: CalculateSignalToNoiseInput
): CalculationResult<SignalToNoise>;
```

This call is synchronous; any supplied provider must follow its explicit synchronous contract.

## CalculateSignalToNoiseInput

The exact contract is declared below; use the domain guide for assumptions and staged integration.

```ts
export interface CalculateSignalToNoiseInput {
  /** Mean signal in electrons. */
  signalElectrons: number;
  /** RMS read noise in electrons. */
  readNoiseElectrons: number;
}
```
